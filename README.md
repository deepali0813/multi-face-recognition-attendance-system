# Multi-Face Recognition and Automated Attendance System

## Overview

This project automates attendance marking in examination halls using CCTV footage.

## Features

- Human Detection using YOLOv8
- Face Detection using RetinaFace
- Face Recognition using ArcFace/DeepFace
- Automated Attendance
- Student Motion Tracking
- Attendance Report Generation

## Tech Stack

- Python
- OpenCV
- YOLOv8
- DeepFace
- ByteTrack
